Technical Architecture

Inside the SentimentAI Engine

An end-to-end Natural Language Processing system converting unstructured movie reviews into calibrated emotional polarity classifications.

End-to-End Workflow

Machine Learning Pipeline

From raw user text input to confidence-scored sentiment prediction:

01
✍️

Review Ingestion

User inputs movie review via asynchronous AJAX POST request.

➔
02
🧹

Text Preprocessing

Lowercase conversion and regex cleaning to filter punctuation and non-alphabetic noise.

➔
03
🔢

TF-IDF Vectorizer

Computes term frequency-inverse document frequency over 5,000 unigram/bigram features.

➔
04
🧠

Logistic Regression

Evaluates linear decision boundary using sigmoid log-odds calculation.

➔
05
🎯

Output & Confidence

Extracts predicted class (POSITIF / NEGATIF) and probability confidence score.

⚙️

Model Hyperparameters & Specs

Algorithm Logistic Regression (L-BFGS)
Feature Extraction TF-IDF (Term Frequency-IDF)
N-gram Range (1, 2) [Unigram + Bigram]
Max Vocabulary 5,000 features
Stop Words English standard filter
Dataset Split 80% Train • 20% Test
Evaluation Metric Accuracy & Probability Score
